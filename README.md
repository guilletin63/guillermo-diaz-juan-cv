# Guillermo Díaz Juan — CV interactivo

CV de una sola página (Cloud Security Specialist / Cloud Architect), bilingüe
español–inglés, con buscador por tecnología y diagramas de arquitectura.

## 🌐 Web publicada (GitHub Pages)

**https://guilletin63.github.io/guillermo-diaz-juan-cv/**

## Contenido del repo

- `index.html` — el sitio completo: HTML, CSS y JS en un único fichero, sin
  dependencias ni build. La única carga externa son las fuentes IBM Plex desde
  Google Fonts.

## Desarrollo local

Basta con abrir `index.html` en el navegador. Si prefieres servirlo:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Publicación

GitHub Pages sirve la rama `main` desde la raíz del repositorio; cada push a
`main` actualiza la web.
